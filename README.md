# Precious Mashawa – Portfolio Website

🌐 **Live site:** [preciousmashawa.co.zw](https://preciousmashawa.co.zw)

The personal portfolio of **Precious Mashawa**, a Software Engineering graduate (BSc Hons, 2:1) from Harare, Zimbabwe. The site presents my projects, skills, industry experience and certificates, and links to my services business, [Precious' Hub](https://hub.preciousmashawa.co.zw).

## Features

- **Responsive, mobile-first design** that works on phones, tablets and desktops
- **Light and dark themes** with a one-click switch
- **Animated network background** drawn on an HTML canvas
- **Data-driven sections**: projects, skills, experience and certificates are all loaded from one file (`js/data.js`), so content can be updated without touching the HTML
- **Typing animation** in the hero section
- **Certificate viewer** that opens each certificate in a pop-up
- **Contact form** that opens a pre-filled email, plus a downloadable CV
- **SEO basics**: meta tags, Open Graph previews, `sitemap.xml` and `robots.txt`

## Built with

- HTML5
- CSS3
- JavaScript (no frameworks)
- Hosted on cPanel with a custom `.co.zw` domain

## Project structure

├── index.html # Main page
├── css/
│ └── style.css # Styles and light/dark themes
├── js/
│ ├── data.js # All site content: projects, skills, timeline, certificates
│ └── main.js # Rendering, animations and interactions
├── assets/ # Images, icons, certificates and CV
├── sitemap.xml
└── robots.txt

## Updating the content

All the content lives in `js/data.js`. To add a project, skill, certificate or experience point, edit the matching list in that file and upload it again. No other files need to change.
